Introduction#

The NVIDIA Jetson Orin Nano Super Developer Kit is a compact generative AI edge computer for developers, students, educators, makers, and robotics researchers.

With the latest software update, Jetson Orin Nano delivers up to 67 INT8 TOPS of AI performance and a 1.7X generative AI performance improvement over its predecessor. Existing Jetson Orin Nano Developer Kit users can get the “Super” performance boost with a software upgrade.

The developer kit is designed for building and experimenting with generative AI models, robotics, vision AI, multimodal agents, and other edge AI workloads using the NVIDIA Jetson software ecosystem.

What This Guide Offers#

This User Guide helps you quickly set up and start developing with Jetson Orin Nano Developer Kit hardware using the latest Jetson software.

Inside, you will find Quick Start Guide, software setup notes, hardware overviews, supported hardware links, and common how-to guidance.

Our goal is to help you get started quickly and use Jetson Orin Nano as an accessible platform for generative AI, robotics, and edge AI development.
